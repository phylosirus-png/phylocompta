# PhyloCompta

Logiciel de comptabilité de bureau pour Madagascar, la France et Maurice — facturation, trésorerie, TVA, immobilisations, stocks et bien plus.

**Site de téléchargement :** https://phylosirus-png.github.io/phylocompta/

---

## Installation

1. Téléchargez `PhyloCompta-Setup-x.x.x.exe` depuis la page [Releases](../../releases) de ce dépôt, ou directement depuis le [site](https://phylosirus-png.github.io/phylocompta/).
2. Double-cliquez sur le fichier téléchargé.
3. Windows peut afficher **« Windows a protégé votre ordinateur »** — c'est normal pour un installateur non signé numériquement. Cliquez sur **« Informations complémentaires »** puis **« Exécuter quand même »**.
4. Lisez et acceptez la politique de confidentialité affichée, puis suivez les étapes de l'assistant d'installation.
5. Lancez PhyloCompta depuis le raccourci créé sur le Bureau ou dans le menu Démarrer.
